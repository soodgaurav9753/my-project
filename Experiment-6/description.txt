1. HTML (Structure)
The HTML defines the basic skeleton of the web page:
- <!DOCTYPE html> → Declares the document as HTML5.
- <head> → Includes metadata, title, viewport settings, and links CSS (styles.css).
- <body> → Contains:
  - A div.container that holds the title and the SVG canvas.
  - <svg> element (id="drawingArea") → This is the drawing canvas where the user can create freehand paths.
  - <script> → Links app.js (the JavaScript logic file).

HTML is kept minimal; it simply provides a container and an SVG canvas.

2. CSS (Presentation)
The CSS defines styling and layout:
- Universal selector (*) ensures consistent box-sizing.
- body uses grid layout to center content, applies a clean sans-serif font, and sets background color.
- .container adds a bordered box around the canvas and title.
- #drawingArea (SVG):
  - Has a border, light background, and a crosshair cursor.
  - Disables text selection (user-select: none) and touch gestures (touch-action: none).

CSS is purely cosmetic, ensuring the drawing tool looks neat and user-friendly.

3. JavaScript (Functionality – Heavy Explanation)
JavaScript powers the interactive drawing logic. It handles mouse events and dynamically creates SVG paths as the user draws.

a. Variable Setup
const svg = document.getElementById("drawingArea");
let isDrawing = false;
let currentPath = null;

- svg → Reference to the <svg> canvas.
- isDrawing → Boolean flag to track if the mouse is pressed (drawing in progress).
- currentPath → Holds the active SVG <path> element being drawn.

b. Mouse Position Helper
function getMousePosition(evt) {
  const rect = svg.getBoundingClientRect();
  return {
    x: evt.clientX - rect.left,
    y: evt.clientY - rect.top
  };
}

- Converts mouse coordinates (clientX, clientY) into SVG-relative coordinates.
- Ensures accurate drawing regardless of canvas position on the page.

c. Start Drawing (mousedown)
When mouse is pressed:
- Sets isDrawing = true.
- Creates a new <path> element inside the SVG namespace.
- Configures stroke style (blue color, thickness, rounded joins/ends).
- Initializes the d attribute (path command) with a MoveTo (M) command at the starting mouse position.
- Adds the path to the SVG canvas.

d. Continue Drawing (mousemove)
Runs only if drawing is active (isDrawing === true).
- Captures the new mouse position and extends the existing path using LineTo (L) commands.
- Each movement creates a continuous freehand line.

e. Stop Drawing (mouseup / mouseleave)
function stopDrawing() {
  isDrawing = false;
  currentPath = null;
}

- Ends the drawing when the mouse button is released or leaves the canvas.
- Resets isDrawing and clears currentPath.
- Also listens to document.mouseup → ensures the drawing stops even if the mouse is released outside the canvas.

4. Workflow Summary
1. User presses mouse → A new path is created starting at that position.
2. User drags mouse → The path continuously updates, forming a line that follows the cursor.
3. User releases mouse → Drawing stops, and the path remains on canvas.
4. User can start again by pressing the mouse in a new spot (multiple paths supported).

5. Key JavaScript Concepts Used
- Event listeners (mousedown, mousemove, mouseup, mouseleave).
- SVG namespace creation (document.createElementNS).
- Path commands (M, L) to build dynamic shapes.
- State management using flags (isDrawing) and references (currentPath).
- Coordinate mapping from screen space to SVG space.

6. Real-World Applications
This drawing tool concept is widely applicable in real-world software systems:
- Online Whiteboards (e.g., Google Jamboard, Miro) → Freehand sketching and collaboration.
- Digital Signature Pads → Capture handwritten signatures using SVG paths.
- Graphic Design Tools (e.g., Figma, Canva) → Enable vector-based freehand drawing and editing.
- E-learning Platforms → Teachers and students can illustrate concepts directly on digital canvases.
- Medical Imaging Annotation → Doctors can mark or annotate X-rays and scans interactively.
- CAD/Engineering Tools → Early sketching of designs in browser-based platforms.

In each case, the ability to track mouse (or touch) movement and convert it into scalable vector paths ensures flexibility, precision, and smooth user interaction.
