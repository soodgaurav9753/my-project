1. Overview
This project is a simple interactive Product Filter Webpage that allows users to filter items (like Clothing, Electronics, and Books) dynamically using JavaScript. The page is structured with HTML, styled minimally with CSS, and powered by JavaScript for interactivity.

2. HTML Structure (Light Overview)
- Container (<div class="container">) holds the entire content.
- A heading (<h2>Product List</h2>) provides context.
- A dropdown menu (<select id="category">) allows the user to select categories:
  - All (shows everything)
  - Clothing
  - Electronics
  - Books
- A display area (<div id="productList"></div>) dynamically updates with filtered products.
- The <script src="script.js"></script> links the JavaScript logic.

HTML is only a skeleton here; all the main work is done by JavaScript.

3. CSS Styling (Light Overview)
The CSS applies simple, clean styling to improve readability:
- Body: Uses Arial font and spacing.
- Container: Bordered box with padding and a fixed width.
- Dropdown (select): Styled for usability with spacing and padding.
- Product items: Each product is a bordered card with padding, margin, and a light background.

CSS is purely cosmetic; it does not affect functionality.

4. JavaScript Functionality (Main Focus)

The JavaScript (script.js) is the engine of this project. It handles:

1. Data Storage
   - Products are stored in a JavaScript array of objects:
     const products = [
       { name: "T-Shirt", category: "Clothing" },
       { name: "Jeans", category: "Clothing" },
       { name: "Headphones", category: "Electronics" },
       { name: "Smartphone", category: "Electronics" },
       { name: "Novel", category: "Books" },
       { name: "Cookbook", category: "Books" }
     ];
   Each product has a name and category. This mimics a small dataset from a product catalog.

2. DOM References
   - document.getElementById("category") → targets the dropdown menu.
   - document.getElementById("productList") → targets the product display area.

3. Dynamic Display Function (displayProducts)
   - Clears old products using productList.innerHTML = "".
   - Applies filtering logic:
     const filtered = filter === "All"
        ? products
        : products.filter(p => p.category === filter);
     - If "All" is selected → show all products.
     - Otherwise → filter by category using Array.prototype.filter().
   - For each product, it creates a new <div>, adds the class "product", sets the text to the product’s name, and appends it to the productList.

4. Initial Rendering
   - On page load, displayProducts("All") is called so that all products are shown by default.

5. Event Listener for User Interaction
   - Attached to the dropdown (categorySelect.addEventListener("change", ...)).
   - Each time the user selects a category, the display updates dynamically.

5. Core JavaScript Concepts Used
- Array Filtering (filter) → Selects items matching the category.
- DOM Manipulation → Creates elements dynamically (document.createElement, appendChild).
- Event Handling → Listens for changes in dropdown selection.
- Separation of Concerns → HTML only structures, CSS only styles, JavaScript handles logic.

6. Real-World Application
This setup is a simplified version of what e-commerce websites use:
- Amazon, Flipkart, Myntra → have large product datasets filtered by category, brand, price, etc.
- Instead of a static array, real websites use APIs or databases for products.
- The logic shown here (filtering, dynamic rendering, event listeners) scales directly into such production systems.

Summary:
- HTML provides the skeleton.
- CSS improves visual appeal.
- JavaScript drives everything: managing data, filtering, and dynamically rendering results.
